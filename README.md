# NS AI Solutions

Premium, responsive landing page for NS AI Solutions — AI consulting and implementation for small and growing businesses.

**Positioning:** Work smarter. Sell faster. Scale with AI.

## Services
- AI Sales Assistants for Instagram, Telegram and other digital channels
- AI chatbots for customer inquiries and support
- Business process automation
- AI integration into existing tools and workflows

## Run locally
This is a static website. Open `index.html` in a browser.

## Deploy to Vercel
1. Import this GitHub repository in Vercel.
2. Select the **Other** framework preset.
3. Leave the build command empty.
4. Set the output directory to `.` if prompted.
5. Deploy. Vercel will assign a `*.vercel.app` address.

## Before launch
- Configure a real contact email or replace the email CTA with a verified business contact channel. The current CTA points to `hello@nsai.ai`, which will not receive mail until the domain and mailbox are configured.
- Confirm the founder/about copy.
- Add case studies only after verified client results are available.
- If you add a contact form, connect it to a form backend or CRM and test submissions.
